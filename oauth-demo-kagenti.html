🔐 GitHub MCP Server OAuth Demo

Hybrid Approach: Browser stores session, Server caches MCP tokens

🏗️ KAgentI Architecture:
Browser (this page) ← Stores Keycloak session token only
↓ HTTP + session token
OAuth Coordinator (port 8185) ← Caches MCP tokens per (user + server)
↓ MCP Protocol + Bearer token
MCP Server (port 8184) ← OAuth discovery + token exchange
✨ Hybrid Approach Benefits:
• Browser: Only stores lightweight session token (simulated)
• Server: Caches all MCP tokens securely per user
• Automatic: Token management is transparent to user
• Secure: Multi-tenant isolation, server-side storage
